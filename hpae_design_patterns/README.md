## 页面内容

1. 简单工厂的产品接口与具体实现类图。
2. 创建函数根据输出端信息选择具体 Manager 的流程。
3. 适配管理器与流包装对象的接口关系。
4. 插件节点的模板方法类图与处理流程。
5. Cluster 与内部处理节点的组合关系。
6. 控制请求入队、通知和执行的时序。

源码依据为 OpenHarmony `multimedia_audio_framework` 的 `75806a3e619d76a98e02b4984f08da8b0727d441` 版本。类图省略无关成员与部分基类，具体边界见逐页讲稿的备答。
